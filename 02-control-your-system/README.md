# Project 2: Control Your System

## Overview
This project focuses on understanding the Linux system, file ownership, permissions, system information, and shell commands for managing the operating system.

## Objective
- Explore system files and directories
- Understand permissions and ownership
- Learn how to inspect system status
- Practice control and management commands

## Technologies
- Linux Shell
- Bash
- System administration commands

## Commands Used
whoami, pwd, ls, id, uname, df, du, free, top, ps, chmod, chown, sudo

## Key Learnings
1. Linux users and groups
2. Permission management
3. System resource monitoring
4. Process and file management

## Challenges & Solutions
Challenge 1: Permission errors - Used sudo and chmod
Challenge 2: Confusing file ownership - Used ls -l and id
Challenge 3: Hard to monitor system load - Used ps, top, and free
