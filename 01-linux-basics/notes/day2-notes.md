# Day 2: File System Basics & Text Processing

## What I Learned
- Understanding Linux filesystem hierarchy
- Copying and moving files safely
- Using grep to filter specific information
- Command piping with |

## Commands Practiced
- cp source destination
- mv source destination
- grep "pattern" filename
- cat file | grep "search"
- head -n 5 file
- tail -n 5 file

## Challenge
Output was too large to read on screen

## Solution
Used `head` and `tail` to view specific portions, and `grep` to filter by keyword

## Key Takeaway
Combining multiple commands (pipes) is more efficient than viewing entire files
