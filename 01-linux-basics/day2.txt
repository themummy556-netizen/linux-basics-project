Day 2: File System & Text Processing

Activities:
- Practiced viewing file contents with cat
- Learned grep for pattern matching
- Used head and tail for partial file viewing

Key Commands:

grep "pattern" filename.txt
head -n 5 filename.txt

cat file.txt | grep "search"
